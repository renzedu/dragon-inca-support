App Store Submission Checklist

DRAGON INCA: Los Bravos del Barrio

Publishing this website does not submit the app or resolve the following App Store Connect requirements automatically. Complete both steps before selecting Add for Review again.

1. Upload a 13-inch iPad screenshot

  1. Run the submitted app build on a supported 13-inch iPad or matching iOS Simulator. Capture the actual app in landscape.
  2. Use an opaque PNG or JPEG at 2752 x 2064 or 2732 x 2048 pixels. Do not stretch an iPhone screenshot to imitate an iPad capture.
  3. In App Store Connect, open Apps, select DRAGON INCA, and open the iOS version being submitted.
  4. In Previews and Screenshots, open the iPad 13-inch display slot (use the media manager if necessary), upload at least one screenshot, and save. Check each localization you are submitting.

The existing 2868 x 1320 screenshots are iPhone screenshots and do not satisfy this iPad requirement.

Apple screenshot specifications

2. Publish App Privacy answers

The submission error requests an Admin. Ask the Account Holder or an Admin to complete this section; Apple also lists App Manager as an eligible role.

  1. Open Apps, select DRAGON INCA, and choose App Privacy in the sidebar.
  2. Set the Privacy Policy URL to https://renzedu.github.io/dragon-inca-support/privacy.html and save.
  3. Select Get Started (or edit the existing answers). Verify the submitted build and all included third-party SDKs against the privacy policy.
  4. Only if accurate for the submitted build, select "No, we do not collect data from this app" and save. Otherwise, disclose every applicable data type and complete its follow-up questions.
  5. Select Publish and confirm the declaration. Saving a draft or adding a policy URL alone does not publish the App Privacy answers.

The current policy describes offline gameplay, no accounts, ads, analytics, or tracking, and progress stored only on the device. The owner must confirm these statements remain accurate before publishing the answers.

Apple App Privacy instructions

Final submission check

  • The 13-inch iPad screenshot is saved in App Store Connect.
  • The public Privacy Policy URL opens without a login.
  • App Privacy responses are published, not left as a draft.
  • The intended build is selected and remaining required metadata is complete.
  • Return to the version page, select Add for Review, then submit from the review submission page when ready.
